# UI-спецификация

Это «макет в виде правил». Агент следует текстовой спеке заметно стабильнее, чем картинке: из скриншота он угадывает отступы, из таблицы — читает.

Скриншот референса (`docs/reference/customize-screen.jpg`) задаёт **состав и сценарий**. Этот документ задаёт **внешний вид**. При конфликте побеждает этот документ.

---

## Концепция

Не модальное окно настроек, а полноэкранная рабочая студия — ближе к препресс-редактору, чем к форме в настройках приложения.

**Ключевое решение: интерфейс нейтрально-графитовый, без собственного цветного акцента.** На этом экране пользователь выбирает цвета своего бренда. Если UI сам будет ярко-синим, он начнёт конкурировать с настраиваемым документом и исказит восприятие выбранного цвета. Единственное цветное пятно на экране — сам счёт.

Из этого же следует, что кольцо фокуса — цвета чернил, а не синее.

## Токены

Объявляются как CSS-переменные в `app/globals.css`, пробрасываются в утилиты через `theme.extend` в `tailwind.config.ts`. Ни одно значение не хардкодится в компонентах.

### Цвета — светлая тема

| Токен | Значение | Применение |
|---|---|---|
| `--canvas` | `#e7e8ec` | Полотно под бумагой |
| `--surface` | `#fdfdfe` | Панели, поля ввода |
| `--surface-sunken` | `#f4f5f7` | Рельс, фон тумблера |
| `--surface-hover` | `#f0f1f4` | Ховер строк и кнопок |
| `--surface-active` | `#e8eaee` | Нажатое состояние |
| `--border` | `#e1e3e8` | Границы по умолчанию |
| `--border-strong` | `#ccd0d8` | Ховер границы, скроллбар |
| `--ink` | `#14161b` | Основной текст |
| `--ink-muted` | `#656b77` | Подписи полей |
| `--ink-subtle` | `#949aa6` | Только плейсхолдеры (см. ADR-17 — счётчики и подсказки перенесены на `ink-muted` по контрасту) |
| `--accent` | `#14161b` | Активные состояния |
| `--accent-ink` | `#ffffff` | Текст на акценте |
| `--danger` | `#c0362c` | Ошибки валидации |

### Цвета — тёмная тема

`--canvas` `#0e0f12` · `--surface` `#191b1f` · `--surface-sunken` `#131417` · `--surface-hover` `#22252a` · `--border` `#282b31` · `--border-strong` `#3b3f47` · `--ink` `#eceef1` · `--ink-muted` `#99a0ab` · `--ink-subtle` `#6d7380` · `--accent` `#eceef1` · `--accent-ink` `#14161b`

Переключение — атрибут `data-theme="dark"` на `<html>`. **Бумага остаётся белой в обеих темах** — это лист, а не поверхность интерфейса.

### Размеры

| Токен | Значение |
|---|---|
| Скругления | `--r-xs` 4 · `--r-sm` 6 · `--r-md` 8 · `--r-lg` 12 · `--r-xl` 16 |
| Высота контрола | `--control-h` 32px |
| Ширина рельса | `--rail-w` 60px |
| Ширина панели | `--panel-w` 336px |
| Высота шапки | `--topbar-h` 52px |

Плотность инструментальная: контрол 32px вместо привычных 40px, чтобы в панель помещалось больше настроек без скролла.

### Типографика

Шрифт интерфейса — системный стек (`-apple-system`, `Segoe UI`, Roboto). Никаких веб-шрифтов: ноль сетевых запросов, ноль сдвига макета, независимость сборки от внешней сети.

| Роль | Размер / интерлиньяж | Начертание | Цвет |
|---|---|---|---|
| Заголовок секции | 13 / 20 | 600 | `ink` |
| Подпись поля | 12 / 18 | 500 | `ink-muted` |
| Значение в поле | 14 / 22 | 400 | `ink` |
| Подсказка, ошибка | 11 / 16 | 400 | `ink-muted` / `danger` (ADR-17) |
| Кнопка | 13 / 20 | 500 | по варианту |

Числа в суммах — `tabular-nums`, иначе колонка итогов «пляшет» при вводе.

### Тени и движение

Тени только у бумаги и всплывающих элементов. Панели разделяются границами, не тенями.

Переходы 140–160 мс, `cubic-bezier(0.32, 0.72, 0, 1)`. Анимируются только `opacity` и `transform`. При `prefers-reduced-motion` всё отключается.

## Компоненты

### Кнопка

| Вариант | Фон | Текст | Граница |
|---|---|---|---|
| Primary | `accent` | `accent-ink` | нет |
| Secondary | `surface` | `ink` | `border` |
| Ghost | прозрачный | `ink-muted` | нет, при ховере фон `surface-hover` |
| Danger-ghost | прозрачный | `danger` | нет |

Высота 32px (28px для иконочных в шапке), скругление `--r-md`, горизонтальный padding 12px.

### Поле ввода

Высота 32px, граница `border`, скругление `--r-md`, padding 10px. Ховер — граница `border-strong`. Фокус — та же граница плюс общее кольцо фокуса. Ошибка — граница `danger`, сообщение под полем 11px.

### Тумблер

Radix `Switch`, 34×20, ползунок 14px со сдвигом `translateX(3px → 17px)`. Выключен — фон `surface-sunken`, граница `border-strong`. Включён — фон и граница `accent`, ползунок `accent-ink`. CSS Module: состояние приходит атрибутом `[data-state]`.

### Цветовое поле

Свотч 24×24 со скруглением `--r-sm` и внутренней рамкой `rgb(0 0 0 / 0.1)` — иначе светлые цвета сливаются с фоном. Клик открывает Radix `Popover` с `HexColorPicker` из `react-colorful`, рядом инпут для hex с валидацией и палитра пресетов 8 штук.

Если выбранный цвет даёт контраст с белой бумагой ниже 3:1 — под полем появляется предупреждение о читаемости. Не блокирующее: это подсказка, а не запрет.

### Строка настройки

Подпись слева, контрол справа, выравнивание по центру, вертикальный padding 8px. Разделители между группами — линия `border` с отступом 16px сверху и снизу.

### Бумага

Ширина 794px (A4 при 96 dpi), белый фон в обеих темах, скругление 2px, многослойная тень. Масштабируется через `transform: scale()` от зума, `transform-origin: top left`.

Тема документа прокидывается CSS-переменными на корне бумаги: `--tpl-primary`, `--tpl-secondary`, `--tpl-font`, `--tpl-density`. Благодаря этому перетаскивание пикера меняет одну переменную, а не вызывает React-рендер поддерева.

## Адаптив

| Ширина | Поведение |
|---|---|
| ≥ 1280 | Полный трёхзонный макет |
| 1024–1279 | Панель сужается до 300px, холст поджимается |
| 768–1023 | Рельс только иконки без подписей |
| < 768 | Вертикальный режим: сегментированный переключатель «Настройки / Предпросмотр», зоны по очереди; зум 100%, скролл холста, вписать — кнопка Fit; тач-цели не меньше 44×44 |

Горизонтального скролла у body быть не должно ни на одной ширине.

---

## Доступность

- У каждого поля `<label for>`; тумблеры — `role="switch"` с `aria-checked` (даёт Radix)
- Рельс разделов — `role="tablist"`, переключение стрелками
- Кольцо фокуса видимое на всех интерактивных элементах: `outline: 2px solid var(--ink)`, `outline-offset: 2px`
- Контраст текста не ниже 4.5:1 в обеих темах
- Печать: `@media print` скрывает интерфейс, бумага печатается на всю страницу без зума

## Проверка перед сдачей

- [ ] Ни одного хардкоженного цвета в компонентах — только токены
- [ ] Тёмная тема переключается сменой переменных, без дублирования классов
- [ ] Перетаскивание пикера не вызывает лишних рендеров (React DevTools → Highlight updates)
- [ ] Все четыре брейкпоинта проверены живьём
- [ ] Клавиатурой проходится весь экран, фокус нигде не теряется
- [ ] Печать даёт чистый лист без панелей
